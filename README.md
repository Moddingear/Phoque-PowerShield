= Phoque Power Shield

This is an example shield for the Phoque-series of brushless drivers. Includes:
- XT60 connector
- 2.8Ohm configurable PCB resistor (can overheat, be careful, shouldn't be left on)
- Extra capacitors (Recommend JIERR PA63V470M10X17 for the through-hole)

This shield can be connected to the main board using 4mm M3 brass standoffs.

Feel free to modify to suit your needs.
